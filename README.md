# Hospital-Department-Backend-
A backend-based Hospital Management System built using Python, FastAPI, and SQLite. Features RESTful APIs with complete CRUD operations to manage hospital records, demonstrating backend development, database integration, and efficient server-side data management.
# Key Features :-
1-Patient record management.
2-Create, retrieve, update, and delete records.
3-SQLite database integration
4-RESTful API architecture.
5-Backend API endpoints.
6- Structured request and response handling.
# Tech Stack Used- Python(Backend Programming)
FASTAPI(API Development)
SQLite(Database Management)
Pydantic(Data Validation)
SQL(DB Queries)
